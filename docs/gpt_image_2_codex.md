# GPT Image 2 через Codex Plus

Функция добавляет в Ауф отдельную модель с отображаемым именем `GPT Image 2`.
Она использует существующий изолированный Hermes/Codex runtime, авторизованный
через ChatGPT Plus, а не OpenAI API key.

## Возможности

- режим `Только текст`: 0 референсов;
- режим `Фото + текст`: от 1 до 5 референсов;
- промт до 8000 символов, максимум два сообщения;
- анализ референсов выполняет Каэль без ручного назначения ролей;
- модель анализа: GPT-5.6 Sol, Terra или Luna;
- усилие анализа: low, medium, high, xhigh или max;
- ровно одна генерация без автоматической перегенерации;
- итоговый формат: JPEG quality 95;
- выбор условных уровней 1K, 2K и 4K отсутствует;
- итоговый JPEG сохраняет нативное разрешение источника и при необходимости только подрезается под выбранную пропорцию;
- Telegram получает сжатый preview и отдельный оригинальный JPEG-документ;
- в подписи сохраняются снимки лимитов Codex до и после задачи, когда runtime
  возвращает эти данные.

## Честный экспорт без обещания качества

Codex/ImageGen не предоставляет Velvet надёжный контракт нативных уровней
1K, 2K и 4K. Поэтому пользователь больше не выбирает такой уровень. Значение
`resolution` сохраняется только как внутреннее совместимое поле старого
bot/router протокола и не показывается как качество.

Velvet не увеличивает полученное изображение и не применяет искусственное
повышение резкости. При несовпадении пропорций выполняется центральная обрезка
в пределах исходных пикселей. В Telegram показываются фактические размеры
готового JPEG.

## Конфигурация бота

В `.env.server` бота:

```env
CODEX_IMAGE_ENABLED=true
CODEX_IMAGE_ROUTER_URL=http://hermes-coder-router:8878
CODEX_IMAGE_ROUTER_TOKEN=<тот же client token, что HERMES_CODER_ROUTER_CLIENT_TOKEN>
CODEX_IMAGE_TIMEOUT_SECONDS=3600
```

Функция выключена по умолчанию. При включении отсутствие или слишком короткое
значение `CODEX_IMAGE_ROUTER_TOKEN` блокирует запуск worker, чтобы запросы не
уходили через незащищённый маршрут.

## Развёртывание Hermes

После обновления нужно пересобрать и перезапустить:

1. `hermes-coder-router`, чтобы получить image endpoints;
2. `hermes-coder-velvet`, чтобы смонтировать `codex_image_runner.py`;
3. root-owned sandbox launcher, чтобы использовать обновлённый
   `sandbox_entrypoint.py`;
4. Velvet Bot с указанными переменными окружения.

Package architecture inventory и reviewed exemptions обновляются вместе с
изменениями runtime, поэтому preflight проверяет фактический состав новой модели.
Инвентарь сохранён с меткой `working-tree`, которую использует обязательный CI.

Перед включением в production выполните live smoke: текстовая генерация,
генерация с одним референсом, проверка фактических пикселей и доставки preview +
документа. CI не может
подтвердить доступность встроенного `image_gen` конкретной активной подписки.
