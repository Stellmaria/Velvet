# Локальный ролевой режим Velvet

## Граница данных

Ролевой режим является отдельным доменом. Он не использует архивные таблицы
`characters`, `character_media`, истории, референсы или публикации.

RP-персонажи хранятся только в `rp_characters`. Совпадение имени с архивным
персонажем не создаёт связь между карточками и не копирует данные автоматически.

## Фундамент RP1

Миграция `915_roleplay_foundation.sql` создаёт:

- `rp_characters` — канонические карточки персонажей;
- `rp_sessions` — сценарий, модель, сводку и состояние сцены;
- `rp_session_characters` — участники, их текущее состояние и отношения;
- `rp_messages` — последовательную долговечную историю диалога;
- `rp_memories` — каноническую, эпизодическую, relational и scene-память.

Карточка персонажа разделяет:

- внешность;
- характер;
- манеру речи;
- биографию;
- правила поведения;
- канонические факты;
- примеры реплик;
- служебные заметки.

Все RP-персонажи требуют явного подтверждения совершеннолетия. Это поле относится
к RP-карточке и не читается из архива.

## Контекст

`RoleplayContextBudget` по умолчанию использует:

- окно контекста: 8192 токена;
- максимум ответа: 900 токенов;
- до 16 последних сообщений;
- порог будущей суммаризации: 5600 токенов.

Сборщик формирует запрос в таком порядке:

1. постоянные правила RP;
2. карточки персонажей;
3. сценарий и лор;
4. сводка прошлых событий;
5. текущее состояние сцены;
6. долговременная память;
7. последние сообщения;
8. новое сообщение пользователя.

Оценка токенов пока консервативная и не зависит от конкретного tokenizer. Старые
сообщения отбрасываются из активного окна, но остаются в PostgreSQL. Автоматическое
создание сводки будет отдельным следующим срезом.

## Ollama

Начальная модель для MSI Katana с 16 ГБ RAM:

```powershell
ollama pull R4C3R/qwen3-8b-heretic:q5_k_m
```

Настройки:

```dotenv
RP_ENABLED=true
RP_PROVIDER=ollama
RP_BASE_URL=http://127.0.0.1:11434
RP_MODEL=R4C3R/qwen3-8b-heretic:q5_k_m
RP_NUM_CTX=8192
RP_MAX_OUTPUT_TOKENS=900
RP_TEMPERATURE=0.9
RP_TOP_P=0.92
RP_MIN_P=0.05
RP_REPEAT_PENALTY=1.08
RP_KEEP_ALIVE=30m
RP_SUMMARY_TRIGGER_TOKENS=5600
RP_RECENT_MESSAGE_LIMIT=16
RP_TIMEOUT_SECONDS=600
```

`RP_*` загружаются отдельно через `load_roleplay_settings()` и не зависят от
`AI_VISION_*`.

## Текущее ограничение

RP1 предоставляет persistence, валидацию, сборщик контекста и Ollama text client.
Telegram-редактор карточек, запуск сцены, генерация ответов, автоматическая сводка,
редактор памяти, откат и экспорт будут добавляться последующими изолированными
срезами.
