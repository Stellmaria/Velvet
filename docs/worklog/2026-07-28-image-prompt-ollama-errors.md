# Image-to-prompt Ollama error handling

## Инцидент

Операция `Изображение → промт` получила HTTP 400 от сырой GGUF-модели, затем
`qwen3-vl:8b` закрыл соединение и локальный Ollama перестал принимать запросы.
Последующие попытки завершались `WinError 10061`.

## Исправление

- HTTP-ошибки теперь сохраняют JSON-поле `error` из ответа Ollama;
- `/api/show` проверяет capability `vision` до отправки изображения;
- ожидаемые ошибки модели и недоступность провайдера не создают traceback уровня ERROR;
- документация и `.env.example` используют устойчивую стартовую модель `qwen3-vl:4b`;
- сырой Hugging Face GGUF удалён из рекомендуемой Ollama-конфигурации;
- добавлены regression-тесты HTTP 400/500 и vision capability.

## Эксплуатационный шаг

Перезапустить Ollama, проверить `server.log`, установить `qwen3-vl:4b`, оставить
`AI_VISION_COMPARE_MODEL` пустым и повторить одиночную живую проверку. Для
production использовать `AI_VISION_TIMEOUT_SECONDS=600`; вторую модель включать
только после стабильного одиночного smoke test.
