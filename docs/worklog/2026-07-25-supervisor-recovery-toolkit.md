## Перед началом

### Цель

Расширить безопасную Telegram-консоль Supervisor до практического набора диагностики и восстановления для ситуаций, когда нет прямого доступа к компьютеру с Velvet Bot.

### Исходный контекст

Удалённая консоль принимала только небольшой фиксированный список команд. Из-за неотслеживаемого ZIP-моста Krita операция обновления была заблокирована, а через Telegram нельзя было безопасно проверить расхождение с `origin/main`, сохранить локальные изменения или диагностировать систему.

### Планируемый объём

- расширить Git-диагностику и сравнение с `origin/main`;
- добавить безопасный аварийный stash с неотслеживаемыми файлами;
- добавить предпросмотр очистки и точечное удаление ZIP Krita;
- добавить проверки Python-зависимостей;
- добавить системную диагностику сети, дисков, процессов и задачи Supervisor;
- сохранить exact allowlist и выполнение без shell;
- добавить regression tests для разрешённых и запрещённых команд.

### Критерии готовности

- каждая команда разрешается только в заранее определённый argv;
- произвольные PowerShell/cmd, pipelines и command substitution остаются запрещены;
- `git reset --hard`, force-push и массовая очистка не разрешаются;
- секреты продолжают редактироваться из вывода;
- Telegram callback data остаются в лимите;
- тесты покрывают recovery toolkit и опасные варианты.

### Проверки
