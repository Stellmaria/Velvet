## Перед началом

### Цель

Убрать двойную отправку результата каждой команды безопасной консоли Supervisor.

### Исходный контекст

Watcher редактировал исходную карточку операции после завершения, а затем `_notify_console_result` отправлял в тот же личный чат второе текстовое сообщение с заголовком `📬 Итог команды Supervisor`. Поэтому `ollama list`, состояние моделей и полный набор тестов отображались дважды.

### Планируемый объём

- оставить итог операции в редактируемой исходной карточке;
- не отправлять отдельное текстовое резюме после завершения;
- сохранить доставку `.txt`-вложения для длинного вывода;
- обновить пользовательское уведомление после запуска команды;
- добавить регрессионные асинхронные тесты.

### Критерии готовности

- короткая команда создаёт только одну итоговую карточку;
- длинная команда создаёт одну карточку и одно вложение с полным выводом;
- `_notify_console_result` не вызывает `send_message`;
- watcher продолжает корректно изолировать Telegram-ошибки и cancellation;
- существующая безопасная консоль и allowlist не меняются.

### Риски и ограничения

- отдельное текстовое уведомление в ЛС больше не отправляется при запуске команды из другого чата;
- результат остаётся доступен в исходной карточке и истории операций;
- полный длинный вывод по-прежнему может создавать отдельное сообщение с документом, что является ожидаемым поведением, а не дублем.

## После завершения

### Фактически сделано

- удалена повторная отправка `console_operation_dm_text`;
- `_notify_console_result` теперь занимается только необязательным `.txt`-вложением;
- короткие результаты не создают дополнительных сообщений;
- длинные результаты отправляют только файл полного вывода;
- текст callback изменён на `Карточка обновится автоматически`;
- добавлены тесты короткого и длинного результата.

### Миграции и совместимость
