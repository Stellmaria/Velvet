## Перед началом

### Цель

Перенести capability-aware фото-flow на актуальный `main`, подключить все выбранные модели и показывать точную цену Ауф до постановки задачи в очередь.

### Исходный контекст

Кошелёк, тарифы, резервирование, счета и сверка уже слиты через PR #403. Старый PR #390 конфликтовал с новым runtime и отставал от `main`, поэтому его функциональность переносится свежим интеграционным слоем.

### Планируемый объём

- фото и текст в любом порядке;
- подтверждение входа;
- выбор модели, качества и соотношения сторон;
- модельные лимиты референсов;
- точная цена Ауф и остаток на финальном экране;
- атомарная проверка версии цены при enqueue;
- перенос тестов и capability-документации.

### Критерии готовности

- шесть фото-моделей доступны по capability map;
- финальная кнопка показывает цену Ауф;
- недостаточный баланс не создаёт задачу;
- изменение тарифа после показа блокирует старую цену;
- задача резервирует ровно подтверждённую сумму;
- полный CI зелёный.

### Риски и ограничения

Provider price estimates Qwen, Wan и FLUX требуют production-сверки. Реальные API keys и server smoke недоступны в GitHub integration-среде.

## После завершения

### Фактически сделано

- перенесены Nano Banana 2/Pro, Seedream 5 Pro, Qwen Image 2.0, Wan 2.7 Image и FLUX.2 Pro;
- добавлены capability-specific качества, ratios и лимиты референсов;
- финальный экран показывает цену, баланс, остаток или дефицит;
- ожидаемая версия тарифа и сумма передаются в payload;
- charged queue сравнивает подтверждённую цену внутри транзакции reserve + enqueue;
- после запуска показывается зарезервированная сумма;
- сохранены compatibility callback/FSM keys без пользовательского бренда Мяу.

### Миграции и совместимость

Новых миграций нет. Используются таблицы кошелька и charge, уже доставленные PR #403. Исторические SQL/callback keys остаются compatibility boundary.
