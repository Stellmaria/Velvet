# Grok Imagine Video 1.5 as a selectable model

Дата: 2026-07-30

## Что изменено

- Старый `grok-imagine/image-to-video` сохранён под отдельным внутренним alias.
- Добавлен `grok-imagine-video-1-5-preview` под новым alias `grok_imagine_video_15`.
- В меню выбора видео появились две отдельные кнопки: дешёвый Grok v1 и качественный Grok 1.5.
- Для Grok 1.5 доступны 480p, 720p и настраиваемая длительность 2–15 секунд.
- Новый API payload передаёт `image_urls`, `aspect_ratio`, `resolution`, `duration` и отключённый Kie NSFW checker без устаревшего поля `mode`.
- Добавлены отдельные переменные окружения model id и расчётной себестоимости.

## Совместимость

Старые задачи Grok v1 продолжают сериализоваться и восстанавливаться через прежний alias. Новый model id не подменяет уже существующий маршрут и не меняет контракт очереди для ранее созданных задач.

## Проверка

Добавлены тесты выбора модели, формирования payload, Kie-клиента и конфигурации. Изменённые Python-файлы проходят компиляцию.
