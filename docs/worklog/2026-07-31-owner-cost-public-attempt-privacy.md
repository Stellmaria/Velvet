# Приватность попыток и себестоимость Стэл

Дата: 2026-07-31

## Контекст

Публичный интерфейс генерации не должен показывать внутренний счётчик повторов вида `2/50`, номера успешной попытки, маршрутизацию и себестоимость провайдера. Эти сведения допустимы только в служебном и владельческом контуре.

При этом глобальный создатель Стэл должен видеть не коммерческую цену в VL, а фактическую расчётную себестоимость провайдера без общей или индивидуальной наценки.

## Реализация

- Добавлен отдельный runtime-установщик `auf_owner_cost_privacy_install`.
- Публичный прогресс продолжает проходить через существующий sanitizer.
- Для задач Стэл внутренний прогресс сохраняет счётчик попыток и расчётную стоимость.
- Из публичного итогового чека удалены строки `Попытка`, `Повтор` и `Успешная попытка`.
- Фото- и видеоэкраны Стэл показывают себестоимость провайдера в USD, RUB и BYN.
- На владельческих экранах генерации не показываются VL, пользовательская цена, наценка, выручка или прибыль.
- После постановки задачи в очередь строка резервирования VL для Стэл заменяется блоком себестоимости провайдера.
- Установщик подключён внутри существующего этапа `install_auf_generation_receipts`, поэтому публичный порядок application composition не изменился.

## Проверки

Добавлен `tests/test_auf_owner_cost_privacy.py` с контрактами на:

- удаление `2/50` и других строк попыток из публичного результата;
- отсутствие VL и слова «вельвет» в блоке себестоимости Стэл;
- замену владельческого резервирования на себестоимость;
- сохранение внутреннего прогресса только для глобального создателя.
