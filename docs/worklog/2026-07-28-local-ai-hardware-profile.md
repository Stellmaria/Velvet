- Дата: 2026-07-28
- ID: `2026-07-28-local-ai-hardware-profile`
- Линия/фаза: Velvet Supervisor / локальные AI-модели

## Перед началом

### Цель

Добавить безопасный удалённый аппаратный профиль компьютера, достаточный для обоснованного выбора текстовой модели для ролевого общения и более сильной vision-модели Ollama.

### Исходный контекст

- ранее подтверждалась видеокарта класса RTX 3050 Ti Laptop с ограниченной VRAM, но точные текущие параметры после перезапуска не были собраны одним отчётом;
- модели Ollama переносились на диск `E:`;
- выбор между 4B, 8B и более крупными моделями зависит не только от VRAM, но также от общего объёма и доступности RAM, файла подкачки, CPU, свободного места и состояния драйвера;
- текущая безопасная консоль показывала диски и список моделей раздельно, но не формировала профиль для планирования локального AI;
- устанавливать модели до получения точных данных означало бы расходовать десятки гигабайт методом проб и человеческой надежды.

### Планируемый объём

- собрать ОС и архитектуру;
- определить модель CPU, физические и логические ядра;
- получить общий и доступный объём RAM и pagefile;
- получить GPU, VRAM, свободную VRAM, версию драйвера и поддерживаемую CUDA через `nvidia-smi`;
- использовать Win32_VideoController только как fallback;
- показать свободное место на `C:` и `E:`;
- показать питание ноутбука и заряд батареи;
- показать версию Ollama, активный `OLLAMA_MODELS` и модели, загруженные в память;
- добавить одновременно человекочитаемый вывод и однострочный `PROFILE_JSON`;
- встроить отчёт в существующую быструю команду `Ollama: состояние vision` без нового пользовательского ввода.

### Критерии готовности

- отчёт запускается удалённо одной существующей кнопкой;
- никакие параметры компьютера не изменяются;
- subprocess-команды фиксированы и выполняются с `shell=False`;
- не собираются серийные номера, UUID, MAC-адреса, имя пользователя и секреты;
- Linux CI может импортировать и тестировать модуль без Windows API;
- вывод содержит достаточно данных для последующего сравнения актуальных моделей Ollama;
- все обязательные CI-проверки проходят.

### Риски и ограничения

- `Win32_VideoController.AdapterRAM` на некоторых системах неточен, поэтому для NVIDIA приоритет имеет `nvidia-smi`;
- свободная VRAM меняется в зависимости от запущенных программ и является снимком на момент команды;
- версия CUDA из `nvidia-smi` показывает максимальную версию, поддерживаемую драйвером, а не установленный CUDA Toolkit;
- аппаратный профиль не выбирает и не скачивает модели автоматически;
- рекомендации по конкретным моделям нужно строить после получения отчёта и проверки актуального каталога Ollama.

## После завершения

### Фактически сделано

- добавлен модуль `velvet_supervisor.hardware_profile`;
- RAM и pagefile на Windows читаются через `GlobalMemoryStatusEx`;
- питание и батарея читаются через `GetSystemPowerStatus`;
- CPU и физические ядра читаются фиксированным запросом CIM;
- NVIDIA GPU читается через фиксированный `nvidia-smi --query-gpu`;
- версия CUDA извлекается из заголовка `nvidia-smi`;
- fallback GPU использует фиксированный CIM-запрос Win32_VideoController;
- диски `C:` и `E:` проверяются через `shutil.disk_usage`;
- Ollama диагностируется через `ollama --version` и локальный `/api/ps`;
- вывод содержит краткую русскую сводку и `PROFILE_JSON`;
- аппаратный профиль автоматически добавляется только к действию `ollama_recovery status`;
- существующая быстрая кнопка `Ollama: состояние vision` остаётся точкой входа.

### Миграции и совместимость

Миграции PostgreSQL не требуются. HTTP API, callback-контракт Telegram и реестр безопасных команд не меняются. Существующие действия `configure`, `start`, `pull`, `show` и `repair` сохраняют прежний вывод и поведение.

### Проверки

Добавлены тесты:

- разбора `nvidia-smi` для имени GPU, VRAM, драйвера и CUDA;
- человекочитаемого вывода;
- корректности `PROFILE_JSON`;
- запуска hook только для `ollama_recovery status`;
- отсутствия вывода hook для `repair` и других действий.

Перед merge должны пройти tests workflow, type check, Docker build и project notes contract.
