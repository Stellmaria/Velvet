## Перед началом

### Цель

Устранить зависимость стоимости генераций от маркетинговой сетки пакетов, добавить резерв переменных расходов, сохранить различия между качествами и защитить индивидуальные тарифы от убыточных значений.

### Исходный контекст

После PR #589 публичные пакеты VL стали 20/50/75/100/150/250. Расчёт генераций продолжал использовать минимальную стоимость VL среди активных пакетов. Поэтому изменение пакетов автоматически меняло количество VL за модели. Индивидуальная наценка заменяла глобальную без нижней границы, а округление могло уравнять разные уровни качества.

### Планируемый объём

- Добавить стабильную расчётную цену 4 ₽ за VL, независимую от пакетов.
- Добавить операционный резерв 5% поверх прямой стоимости провайдера.
- Установить безопасный минимум индивидуальной наценки 15%.
- Сохранить таблицу индивидуальных переопределений.
- Добавить минимальные VL для SKU и качества.
- Повысить Nano Banana Pro до премиальной сетки 2/3/4 VL.
- Ограничить активный каталог изображений пятью утверждёнными моделями.
- Добавить отдельные маршруты и цены для Wan 2.7 и Wan 2.7 Pro.
- Обновить интеграционные и контрактные тесты.

### Критерии готовности

- Расчётчик генераций не читает `auf_package_prices`.
- Изменение пакетов не меняет количество VL за генерацию.
- Общая наценка остаётся 42,86%.
- Индивидуальная наценка не может быть ниже 15%.
- Прямые расходы учитываются с операционным резервом 5%.
- Nano Banana Pro стоит 2/3/4 VL.
- Активный каталог изображений содержит только Banana 2, Banana Pro, Seedream 5 Pro, Wan 2.7 и Wan 2.7 Pro.
- Wan 2.7 стоит 1/2 VL за 1K/2K.
- Wan 2.7 Pro стоит 3/4/5 VL за 1K/2K/4K; 4K доступно только без референсов.
- Qwen Image и FLUX нельзя выбрать, тарифицировать или отправить провайдеру новой задачей.
- Все обязательные проверки GitHub Actions зелёные.

### Риски и ограничения

- Часть пользовательских цен увеличится, прежде всего Banana Pro и дорогие режимы Seedance.
- Существующие подтверждённые задачи и счета не пересчитываются.
- Исторические записи стоимости не изменяются.
- Строковые alias удалённых моделей сохраняются для чтения исторических payload, но не имеют активного provider route.
- Production rollout и применение миграции выполняются отдельно после merge.

## После завершения

### Фактически сделано

- Добавлена миграция `migrations/z031_auf_pricing_economy_hardening.sql`.
- Расчёт VL переведён на стабильную цену 4 ₽ за VL.
- Добавлен операционный резерв 5%.
- Добавлен минимальный индивидуальный markup 15%.
- Existing overrides ниже 15% поднимаются до безопасного минимума.
- Минимальные значения VL для SKU хранятся в `auf_price_versions.minimum_velvets`.
- Banana Pro получает сетку 2/3/4 VL.
- Активный каталог изображений ограничен пятью моделями: Banana 2, Banana Pro, Seedream 5 Pro, Wan 2.7 и Wan 2.7 Pro.
- Wan 2.7 использует provider ID `wan/2-7-image`, качества 1K/2K и сетку 1/2 VL.
- Wan 2.7 Pro использует `wan/2-7-image-pro`, качества 1K/2K/4K и сетку 3/4/5 VL; 4K доступно только в режиме «Только текст».
- Qwen Image и FLUX удалены из capability, provider routing, payload builders, env-конфигурации, server preflight и pricing.
- Их строковые alias сохранены только для десериализации исторических задач; новый запуск завершается отсутствием provider/pricing route.
- Повторный Wan-пересчёт больше не читает `auf_package_prices`; количество результатов тарифицируется пропорционально один раз.

### Миграции и совместимость

- Новая миграция добавляет поля `quote_rub_per_vl`, `operational_cost_buffer_percent` и `minimum_user_markup_percent` в `auf_economy_settings`.
- В `auf_price_versions` добавляется `minimum_velvets` с безопасным значением по умолчанию 1.
- Активные Qwen/FLUX версии закрываются через `effective_to`.
- Для Wan 2.7 и Wan 2.7 Pro создаются отдельные версионированные строки цен.
- Исторические завершённые версии, ledger-записи, балансы, счета и подтверждённые задачи не пересчитываются.
- Таблица `auf_user_markup_overrides` сохраняется. Значения ниже 15% поднимаются до нового защитного минимума.
- Общая наценка 42,86% и текущая сетка пакетов VL не изменяются.
