# Telegram progress network warning

### Планируемый объём

- Не считать временный `TelegramNetworkError` при обновлении прогресса ошибкой генерации.
- Не задерживать и не останавливать provider-кампанию из-за недоступности Telegram edit API.
- Отбрасывать разговорный отказ «не могу создавать небезопасные изображения» как недостоверную техническую причину GRS.

### Критерии готовности

- `ServerDisconnectedError` при `edit_message_text` записывается как WARNING без traceback.
- Генерация и очередь продолжают работу независимо от progress-сообщения.
- Структурированные причины вроде `IMAGE_SAFETY` сохраняются.
- Все CI-проверки проходят.

### Риски и ограничения

- При временном обрыве одно обновление прогресса может быть пропущено; следующее успешное обновление синхронизирует карточку.
- Неопределённая платная отправка без task id по-прежнему останавливает кампанию для защиты баланса.
- Видимые `Мяу` и задержка 30 секунд в предоставленном логе означают, что запущенный процесс ещё не использует merge commit с Auf и instant retry.
