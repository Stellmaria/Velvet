## Перед началом

### Цель

Настроить фактическое использование установленного набора локальных моделей всеми AI-задачами бота и устранить повторную запись моделей Ollama на переполненный диск C:.

### Исходный контекст

После восстановления в Ollama API были зарегистрированы три vision-модели: стандартная `qwen3-vl:8b`, uncensored 8B и uncensored 4B. Загрузка text 9B остановилась на 21%, потому что новый процесс Ollama писал partial blob в `C:\Users\aamch\.ollama\models`, несмотря на проектное значение `OLLAMA_MODELS=E:\OllamaModels`.

Аудит кода показал, что `AI_TEXT_MODEL` присутствовал в `.env`, но текстовый обработчик оформления продолжал использовать `AI_VISION_MODEL`. Большинство остальных AI-клиентов также знали только одну модель и не использовали compare/fallback-настройки. Наличие четырёх строк конфигурации само по себе, как выяснилось, не превращает их в архитектуру.

### Планируемый объём

- запустить отдельный экземпляр Velvet Ollama на порту 11435;
- закрепить `OLLAMA_MODELS` и `OLLAMA_HOST` в project `.env`, User environment и runtime environment;
- безопасно перенести complete/partial blobs и manifests из стандартного каталога C: в E:;
- продолжить загрузку text 9B из перенесённого partial blob;
- добавить единый маршрутизатор моделей для всех наследников `VisionClient`;
- направить текстовые клиенты на `AI_TEXT_MODEL`;
- использовать compare и fallback-модели при отсутствии или отказе основной модели;
- сохранить общий локальный lock и лимит одной загруженной модели;
- добавить регрессионные тесты.

### Критерии готовности

- Supervisor-команды Ollama обращаются к выделенному API `127.0.0.1:11435`;
- процесс Ollama получает `OLLAMA_MODELS=E:\OllamaModels` до запуска;
- partial blob с C: переносится на E: без удаления более полного файла;
- дубликаты blobs/manifests на C: удаляются только при безопасном совпадении;
- текстовая задача выбирает text 9B, а при её отсутствии — доступную uncensored 8B;
- визуальные задачи видят primary, compare и fallback-модели;
- ни один Telegram-ввод не превращается в произвольную системную команду;
- полный CI проходит.

### Риски и ограничения

- перенос файлов выполняется только после остановки процессов Ollama;
- blob с одинаковым именем, но отличающимся размером не удаляется автоматически;
- на RTX 3050 Ti 4 ГБ модели выполняются последовательно под единым lock;
- fallback обеспечивает выполнение задачи, но разные модели могут давать различающийся стиль и точность;
- после изменения API-порта требуется перезапуск Supervisor и бота.
