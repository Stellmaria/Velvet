# Сессия: баланс аккаунта Byesu в служебном экране

- Дата: 2026-08-02
- ID: `byesu-account-balance-20260802`
- Линия/фаза: owner service balances
- Статус: `готово к проверке`
- Ветка: `fix/byesu-balance-key-status`

## Перед началом

### Цель

Исправить служебный экран балансов так, чтобы он использовал отдельный ключ только для чтения общего баланса аккаунта Byesu и не смешивал этот показатель с квотами отдельных API-ключей.

### Подтверждённая причина

Production-запрос к `https://byesu.com/dashboard/billing/subscription` возвращал `HTTP 401 Invalid token`. Обработчик скрывал конкретный статус под общей строкой `баланс временно недоступен`, а для авторизации сначала выбирал общий `BYESU_API_KEY`.

## После изменений

### Фактически сделано

- добавлен приоритетный `BYESU_BALANCE_API_KEY`;
- сохранена обратная совместимость с `BYESU_API_KEY` и профильными AI-ключами;
- HTTP 401, 403 и 429 преобразуются в безопасные понятные статусы без вывода ответа провайдера или секрета;
- сетевые, timeout- и JSON-ошибки различаются;
- подпись в Telegram уточнена до `Byesu · баланс аккаунта`;
- добавлены тесты выбора отдельного ключа, успешного `balance_usd`, HTTP 401 и безопасного сообщения пользователю.

### Production-настройка после merge

В `/srv/velvet/.env.server` требуется добавить действующий ключ того же аккаунта:

```env
BYESU_BALANCE_API_KEY=sk-...
```

Квоты ключей `Hermes-Codex` и `Hermes-GPT-Pro` не суммируются и не отображаются как баланс аккаунта.

### Проверки

- целевые unit-тесты добавлены в `tests/test_auf_menu_provider_balance_hotfix.py`;
- полный GitHub Actions workflow запускается на draft PR;
- секреты и значения ключей в Git не добавлены.
