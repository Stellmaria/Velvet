# Original video file delivery hotfix

## Проблема

Успешная видеогенерация могла прислать пользователю только Telegram-предпросмотр. Исходный MP4 отправлялся вторым сообщением, и если Telegram отклонял загрузку документа, ошибка оставалась только в техническом логе. Предыдущее исправление находилось в stacked PR поверх незалитой ветки и не попадало в обновления из `main`.

## Решение

- hotfix создан напрямую от актуального `main`;
- оригинальный MP4 отправляется первым как Telegram document;
- для MP4 включён `disable_content_type_detection=True`;
- видеопредпросмотр отправляется отдельным вторым сообщением;
- ошибки документа и предпросмотра обрабатываются независимо;
- при частичной доставке пользователь получает явное уведомление;
- ошибка Telegram не запускает повторную платную генерацию.

## Покрытие

Регрессии охватывают все видеомодели текущего `main`:

- Grok Imagine v1;
- Grok Imagine Video 1.5;
- Seedance 1.5 Pro;
- Wan 2.7.
