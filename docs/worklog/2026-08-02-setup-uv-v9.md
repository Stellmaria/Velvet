## Перед началом

### Цель

Обновить закреплённый GitHub Action `astral-sh/setup-uv` до v9 и восстановить контракт тестов, который ошибочно требовал SHA предыдущей версии.

### Исходный контекст

Dependabot обновил action до v9. Установка uv, восстановление кеша, type-check, security и backup проходили, но тест `test_type_check_workflow_uses_pinned_development_dependencies` был привязан к SHA v8.1.0 и блокировал PR независимо от фактической работоспособности workflow.

### Планируемый объём

- обновить ожидаемый SHA в контрактном тесте;
- сохранить явное pruning-поведение для кеша type-check workflow;
- повторно прогнать обязательные проверки.

### Критерии готовности

- type-check workflow использует закреплённый SHA setup-uv v9;
- контрактный тест проверяет актуальный SHA;
- type-check кеш явно очищается перед сохранением;
- обязательные CI-проверки проходят.

### Риски и ограничения

В setup-uv v9 значение `prune-cache` по умолчанию изменено на `false`. Для type-check workflow прежнее поведение сохранено явным `prune-cache: true`; остальные workflow принимают новый upstream default, что влияет на размер кеша, но не на установку зависимостей.

### Миграции и совместимость

Runtime и данные приложения не затрагиваются. Изменения ограничены GitHub Actions и контрактным тестом.

## После завершения
