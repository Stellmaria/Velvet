## Перед началом

### Цель

Исправить служебный экран балансов так, чтобы Byesu показывал фактический остаток квоты выбранного API-ключа, совпадающий с таблицей ключей в консоли, а не исходный жёсткий лимит ключа.

### Исходный контекст

Production-запрос `/dashboard/billing/subscription` для ключа Hermes-Codex вернул `hard_limit_usd=10.001866`. Запрос `/dashboard/billing/usage` вернул `total_usage=54.1548`, где единица соответствует одной сотой доллара. Консоль Byesu показывает остаток квоты этого ключа `9,46`, что совпадает с расчётом `10.001866 - 54.1548 / 100 = 9.460318`.

Общий кошелёк аккаунта Byesu отображается отдельно и на момент проверки составлял `$1.47`. API-ключ не предоставляет этот общий баланс через используемые совместимые billing endpoints, поэтому служебный экран должен явно описывать значение как квоту конкретного ключа.

### Планируемые изменения

- одновременно запросить subscription и usage для `BYESU_BALANCE_API_KEY`;
- вычислить остаток как `hard_limit_usd - total_usage / 100`;
- не допускать отрицательного отображаемого остатка;
- округлять значение до двух знаков после запятой;
- переименовать строку в `Byesu · остаток квоты ключа`;
- добавить regression-тесты реального production payload и исчерпанной квоты.

### Вне объёма

- получение общего баланса кошелька аккаунта Byesu;
- отображение всех ключей аккаунта;
- изменение квот или статуса ключей;
- изменение production-секретов;
- автоматический deployment сервера.

### Критерии готовности

- payload `hard_limit_usd=10.001866` и `total_usage=54.1548` даёт `$9.46`;
- отрицательный результат ограничивается нулём;
- Telegram явно называет показатель остатком квоты ключа;
- ключи и сырые ответы API не выводятся пользователю;
- обязательные CI-проверки проходят.

### Риски и допущения

- `total_usage` в совместимом billing API измеряется в сотых доллара, как в upstream One API/New API контракте и подтверждено production-значением;
- Byesu может изменить совместимый формат endpoint без версионирования;
- два сетевых запроса выполняются параллельно в пределах прежнего общего таймаута;
- общий баланс аккаунта может быть меньше остатка квоты ключа, поэтому эти значения нельзя смешивать.
