## Перед началом

### Цель

После успешной генерации отправлять пользователю удобный Telegram-предпросмотр и отдельный оригинальный файл без сжатия. Для изображения нужны `send_photo` и `send_document`; для видео нужны `send_video` и `send_document`.

### Исходный контекст

После PR #361 worker скачивал результат Kie байтами. Изображения отправлялись только документом, а видео отправлялись как проигрываемое видео и превращались в документ лишь при отказе Telegram. Пользователь должен получать обе формы результата всегда, а не выбирать между просмотром и оригиналом.

### Планируемый объём

- добавить двойную доставку изображений;
- добавить двойную доставку видео;
- создавать независимый `BufferedInputFile` для каждой Telegram-отправки;
- сохранить fallback на оригинальный документ при отказе предпросмотра;
- обновить unit-тесты доставки.

### Критерии готовности

- изображение успешно отправляется через `send_photo` и `send_document`;
- видео успешно отправляется через `send_video` и `send_document`;
- отказ Telegram принять preview не блокирует оригинальный файл;
- оригинальные байты и расширение файла сохраняются;
- tests, type check, Docker build и project notes contract проходят.

### Риски и ограничения

- Telegram может не принять отдельные форматы изображений или видеокодеки как preview;
- документ ограничен текущим лимитом worker в 50 МБ;
- две Telegram-отправки увеличивают трафик, но не создают повторный provider-запрос и не списывают повторную стоимость Kie;
- временный Telegram API/network failure может сорвать одну или обе отправки.

## После завершения

### Фактически сделано

- добавлены `_send_image_and_document` и `_send_video_and_document`;
- изображение отправляется как фото и затем как оригинальный документ;
- видео отправляется как streaming preview и затем как оригинальный документ;
- preview и документ получают отдельные upload-объекты из одних исходных байтов;
- при `TelegramBadRequest` оригинальный документ всё равно отправляется;
- тесты проверяют обе успешные отправки и оба fallback-сценария.

### Миграции и совместимость

Миграции базы и новые env-переменные не нужны. Формат Kie-задач не изменён. Меняется только Telegram-доставка уже скачанного результата. Существующие модели изображений и видео используют новый общий режим автоматически.
