## Перед началом

### Цель

Добавить версионный каталог тарифов и атомарный жизненный цикл оплаты генераций: расчёт цены, резерв Ауф вместе с созданием `ai_task`, списание после успеха и полный возврат при ошибке или отмене без результата.

### Исходный контекст

PR #397 реализует кошельки и журнал Ауф поверх runtime-ветки #387. Фото-flow #390 пока конфликтует с runtime, поэтому финансовый контур должен подключаться к общему payload `ai_task` и не зависеть от конкретной Telegram-последовательности выбора модели.

### Планируемый объём

- таблица версий тарифов всех утверждённых фото- и видеомоделей;
- таблица charge на задачу с зафиксированной ценой;
- расчёт фиксированной и посекундной стоимости;
- учёт дополнительных референсов Seedream;
- атомарные reserve + enqueue;
- автоматические capture, refund и release при смене статуса задачи;
- исключение системных задач Стэл из ограничений Ауф;
- понятные Telegram-ошибки недостаточного или замороженного баланса;
- unit- и PostgreSQL integration tests.

### Критерии готовности

- задача личного пространства не создаётся без достаточного баланса;
- один dedupe callback не резервирует Ауф повторно;
- цена и версия тарифа сохраняются в charge;
- `success` списывает резерв;
- `error` полностью возвращает резерв;
- `cancelled` освобождает резерв;
- системные задачи Стэл не получают charge;
- терминальную платную задачу нельзя requeue без новой цены;
- все операции выполняются без `float`.

### Риски и ограничения

- ветка является stacked PR поверх #397 и косвенно зависит от #387;
- финальное отображение Ауф в новом фото-review будет согласовано после объединения #390;
- тарифы Qwen, Wan Image, FLUX и дорогих видео остаются настраиваемыми оценками до production smoke-test;
- локальный checkout недоступен, итоговая проверка выполняется GitHub Actions.

## После завершения

### Фактически сделано

- добавлена `meow_price_versions` с активными версиями тарифов;
- добавлена `meow_task_charges` с зафиксированной стоимостью задачи;
- внесены тарифы Nano Banana 2/Pro, Seedream 5 Pro, Qwen Image 2.0, Wan 2.7 Image, FLUX.2 Pro, Grok v1, Grok 1.5, Seedance и Wan 2.7 Video;

- добавлен `MeowChargedTaskQueueService` с одной PostgreSQL-транзакцией reserve + enqueue;
- dispatcher использует charged queue для Meow и обычный путь для остальных AI-задач;
- Стэл обходит Ауф-ограничение, но задача остаётся в общем AI usage accounting;
- SQL-trigger атомарно закрывает reserve при `success`, `error` и `cancelled`;
- добавлен запрет повторного запуска терминальной charged-задачи без нового quote;
- финансовые ошибки показываются пользователю через Telegram alert;
- добавлены PostgreSQL-тесты каталога, dedupe, capture, refund, release, frozen/insufficient balance и bypass Стэл.

### Миграции и совместимость

Добавлена `migrations/z022_meow_task_charging.sql`. Существующие задачи без `meow_task_charges` продолжают работать бесплатно по старому контракту. Новые задачи личных пространств получают charge при enqueue. Формат `ai_tasks.payload` и существующий `AIUsageService` не меняются.
