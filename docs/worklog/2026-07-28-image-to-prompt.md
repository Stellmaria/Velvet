# Сессия: image-to-prompt для архивной панели Qwen

- Дата: 2026-07-28
- ID: `2026-07-28-image-to-prompt`
- Линия/фаза: Velvet AI / UX существующей архивной панели Qwen
- Статус: `частично`
- Ветка: `agent/image-to-prompt`
- Базовый commit: `cf252cd9905e8a4a60fd8054c482282fabecce08`

## Перед началом

### Цель

Добавить в существующую owner-панель `Qwen · работа с архивом` операцию,
которая восстанавливает технический промт по одному изображению через уже
настроенную локальную vision-модель.

### Исходный контекст

Панель уже содержит проверку качества, сравнение с референсом, проверку
`промт ↔ результат`, палитру, оформление и историю AI-заданий. Обратная операция
`изображение → промт` отсутствовала. Первоначальная реализация ошибочно
подключала кнопку только к Qwen-панели рабочего пространства, тогда как
фактический owner-сценарий использует системную архивную панель.

### Планируемый объём

- создать клиент image-to-prompt поверх существующих Ollama и
  OpenAI-совместимых vision endpoints;
- добавить компактную кнопку в архивную Qwen-панель;
- принять фото или image-документ через существующий ForceReply-контракт;
- зарегистрировать операцию в постоянной истории AI-заданий;
- вернуть краткий результат в Telegram и полный текст отдельным `.txt`-файлом;
- сохранить локальную AI-блокировку и существующие настройки `AI_VISION_*`;
- добавить regression-проверку callback action и обновить документацию.

### Критерии готовности

- в `Qwen · работа с архивом` отображается кнопка `🪄 Фото → промт`;
- кнопка создаёт форму загрузки изображения;
- результат сохраняется как AI-задание `image_to_prompt`;
- история показывает понятное название и кнопку повторного запуска;
- Python-файлы компилируются, diff проходит whitespace-проверку;
- целевой unit test и живая Windows/Telegram-проверка выполняются до merge.

### Риски и ограничения

Операция зависит от доступности Ollama и фактической поддержки изображений
выбранной моделью. Supervisor обновляет только настроенную стабильную ветку
`main`, поэтому тестовая ветка устанавливается вручную или после merge.

### Обоснование режима стабилизации

1. Улучшается существующий контур Velvet AI и единая архивная Qwen-панель.
2. Владельцу не требуется переносить изображение во внешний инструмент для
   восстановления промта.
3. Предметная область не расширяется: используются существующие изображения,
   локальный Qwen и журнал AI-заданий.
4. Улучшение проверяется callback regression-тестом, компиляцией и живой
   Telegram-проверкой.
5. Сохраняются `AIJobTracker`, локальная AI-блокировка, конфигурация vision и
   существующая presentation/router граница.
