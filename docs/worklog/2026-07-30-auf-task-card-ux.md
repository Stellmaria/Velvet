## Перед началом

### Цель

Убрать неоднозначный экран, где восемь задач отображаются общим текстовым списком, а все кнопки повторной доставки собраны отдельным блоком ниже и визуально не связаны с конкретными задачами.

### Исходный контекст

Telegram не позволяет прикрепить inline-кнопку к отдельному абзацу одного сообщения. Текущий экран выводит несколько задач в тексте и затем несколько одинаковых кнопок `Доставить`, поэтому пользователь не может уверенно определить, какую задачу откроет каждая кнопка.

### Планируемый объём

- показывать одну задачу за раз;
- выводить модель, статус, тип результата, режим, качество, время и короткий ID;
- заменить техническое `Доставить` на понятное `Получить результат`;
- показывать действие только для успешной задачи;
- добавить навигацию между соседними задачами;
- явно сообщать, что повторная генерация и списание не запускаются;
- убрать формулировку `без операции Ауф`.

### Критерии готовности

- на экране присутствует только одна задача и только одна относящаяся к ней кнопка результата;
- пользователь видит короткий ID и дату задачи;
- кнопка результата не появляется для незавершённых или ошибочных задач;
- переходы `Новее` и `Старее` меняют задачу на одну запись;
- полный CI проходит.

### Риски и ограничения

История остаётся в одном редактируемом Telegram-сообщении. Это намеренно: отдельное сообщение на каждую задачу засоряло бы чат и усложняло обновление статуса.
