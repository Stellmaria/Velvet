## Перед началом

### Цель

Полностью заменить пользовательский бренд «Мяу» на «Ауф» во всём Telegram-интерфейсе и запускать следующую последовательную GRS-попытку сразу после подтверждённого `violation`.

### Исходный контекст

Название «Мяу» было распределено между меню, кнопками, callback-alert, сообщениями очереди, прогрессом, результатами, балансом и ошибками. Попытка GRS после подтверждённого moderation-отказа планировалась через общий backoff очереди, обычно 5–30 секунд.

### Планируемый объём

- централизованно заменить видимые строки «Мяу» на «Ауф» во всех Telegram methods;
- заменить кошачий значок основной кнопки на собачий;
- сохранить внутренние callback id `meow` для совместимости уже отправленных кнопок;
- обнулить retry delay только для подтверждённого GRS `violation`;
- сохранить текущий backoff для сетевых, временных и прочих ошибок;
- сохранить последовательный лимит кампании до 50 попыток;
- добавить регрессионные тесты.

### Критерии готовности

- пользователь не видит «Мяу» в новых Telegram-сообщениях, кнопках, alert и media captions;
- основная кнопка отображается как `🐕 Ауф`;
- callback data и внутренние FSM-контракты остаются совместимыми;
- подтверждённый `violation` получает задержку `0` секунд;
- следующий worker-cycle может сразу взять ту же задачу;
- неопределённый POST без task id по-прежнему останавливает кампанию;
- CI проходит.

### Риски и ограничения

- технические имена модулей и callback-prefix `meow` намеренно не переименовываются, чтобы не сломать старые Telegram-кнопки и сохранённые FSM-состояния;
- мгновенный повтор применяется только к подтверждённому provider-отказу;
- параллельные платные задачи не запускаются;
- фактическая скорость следующей попытки зависит от свободного worker-cycle и очереди, но искусственная задержка убрана.

## После завершения

### Фактически сделано

- добавлен глобальный branding-layer для всех исходящих aiogram Telegram methods;
- заменяются заголовки, обычный текст, callback-alert, подписи медиа, команды и вложенные кнопки;
- `🐈 Мяу` преобразуется в `🐕 Ауф`;
- внутренние callback data не изменяются;
- GRS moderation retry теперь записывается в очередь с нулевым base/max delay;
- пользовательское сообщение сообщает, что следующая попытка запускается сразу;
- другие классы ошибок сохраняют прежний backoff;
- добавлены unit-тесты вложенной кнопки, текста, callback compatibility и retry delay.

### Миграции и совместимость

Миграции PostgreSQL не требуются. Существующие callback data `meow`, FSM-классы и имена модулей сохранены. Старые уже отправленные кнопки продолжат работать, а новые ответы показывают бренд «Ауф».

### Проверки

Добавлены тесты глобального преобразования Telegram method payload, сохранения callback data, нулевой задержки для подтверждённого `violation`, обычного backoff для прочих ошибок и текста мгновенного перезапуска.
