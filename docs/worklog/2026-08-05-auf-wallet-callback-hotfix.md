## Перед началом

### Цель

Устранить production-ошибку построения клавиатуры кошелька, возникавшую из-за символа `:` внутри поля `value` структуры `AufCallback`.

### Исходный контекст

После rollout PR #609 бот оставался healthy, но открытие кошелька завершалось `ValueError: Separator symbol ':' can not be used in value value='20:RUB'`. Проверка показала, что дефект присутствовал и в предыдущем production SHA, поэтому rollback приложения его не устранял.

### Планируемый объём

- заменить внутренний разделитель суммы и валюты на callback-safe символ;
- сохранить разбор старого числового значения как RUB;
- проверить упаковку и распаковку callback для всех публичных пакетов;
- проверить клавиатуры RUB и USD и лимит Telegram callback data.

### Критерии готовности

- клавиатура кошелька строится для RUB и USD без исключений aiogram;
- сумма и валюта проходят round-trip через callback;
- старое значение без валюты остаётся совместимым;
- callback data всех кнопок не превышает 64 байта;
- обязательный CI зелёный.

### Риски и ограничения

Изменение не затрагивает схему БД, миграции, балансы, revenue lots или P&L. Символ `|` выбран только как внутренний разделитель поля callback и не передаётся провайдеру платежей.

## После завершения

### Фактически сделано

- добавлен callback-safe разделитель `|` для значения пакета;

- добавлены проверки упаковки, round-trip, клавиатур RUB/USD и 64-байтного лимита.
