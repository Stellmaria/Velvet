## Перед началом

### Цель

Подключить к Velvet отдельную облачную текстовую модель для личной ролевой игры, обеспечить канон, историю и долговременную память, а также подготовить проект к переносу с Windows на Linux-сервер без локального Qwen/Ollama.

### Исходный контекст

В проекте существовали локальный vision-контур Ollama и маршрутизация Qwen, но не было рабочего облачного РП-клиента, постоянных РЛ-сессий, истории, памяти и Telegram-команд. После смены инфраструктурного решения локальный инференс больше не является целевой архитектурой.

### Планируемый объём

- отделить текстовые модели от vision-настроек;
- реализовать OpenAI Responses API и OpenAI-compatible Chat Completions;
- добавить облачный fallback;
- хранить сессии, канон, реплики и резюме в PostgreSQL;
- автоматически сворачивать старую историю;
- добавить Telegram-команды и тесты;
- подготовить Docker Compose для сервера и изолированного Hermes Agent;
- убрать Ollama из активного контейнерного развёртывания;
- сохранить AI-функции выключенными до живой проверки API и выбранных моделей.

### Критерии готовности

- облачная модель выбирается без изменения кода;
- OpenAI-запросы используют Responses API и `store=false`;
- OpenAI-compatible провайдер работает через `/chat/completions`;
- локальный Ollama не может использоваться как РП-провайдер;
- канон, резюме и последние сообщения входят в каждый ход;
- старые сообщения сворачиваются в память;
- РЛ включается отдельно для чата и пользователя;
- длинные ответы делятся по лимиту Telegram;
- Hermes и Codex не получают production-секреты и прямой доступ к запущенному контейнеру;
- command и architecture inventories остаются зелёными.

### Риски и ограничения

- качество и допустимый контент зависят от выбранной модели и правил облачного провайдера;
- API требует отдельного оплачиваемого ключа;
- точные названия RP и VL-моделей должны быть подтверждены живым запросом к BYESU;
- первая версия хранит одну активную историю на пару `chat_id + user_id`;
- live-запрос к платному API не выполняется в CI;
- старые Qwen-названия классов и интерфейса будут переименованы отдельным рефакторингом после стабилизации облачного VL-контура.

## После завершения

- добавлен домен `velvet_bot.domains.roleplay` с моделями, PostgreSQL storage, service, factory и provider clients;
- реализованы OpenAI Responses API и OpenAI-compatible Chat Completions;
- локальный Ollama удалён из РП-клиента и тестов;
