## Перед началом

### Цель

Сделать существующий интерфейс генерации изображений «Мяу» доступным непосредственно из главного owner-меню Velvet Archive, без обязательного перехода через список пространств.

### Исходный контекст

Kie.ai flow уже был реализован и зарегистрирован через `WorkspaceCallback(action="meow")`, однако кнопка находилась только в домашнем меню конкретного пространства. В системном центре управления владелец видел архив, персонажей, пространства, Supervisor, Qwen и другие разделы, но не видел прямого входа в генерацию.

### Планируемый объём

- добавить отдельную заметную кнопку `🐈 Мяу` в системное owner-меню;
- направить её в существующий flow системного пространства;
- не создавать второй обработчик и отдельную очередь генерации;
- обновить справку;
- закрепить callback unit-тестом.

### Критерии готовности

- кнопка отображается в `build_owner_main_keyboard()` отдельной строкой;
- callback содержит `meow` и `DEFAULT_WORKSPACE_ID`;
- нажатие обслуживается существующим workspace-router;
- callback укладывается в лимит Telegram;
- тесты, type check, Docker build и project notes contract проходят.

### Риски и ограничения

- генерация остаётся owner-only и зависит от `KIE_ENABLED`;
- кнопка использует системное пространство как контекст библиотеки референсов;
- ветка «Оживить» остаётся заглушкой текущего Kie photo-среза.
