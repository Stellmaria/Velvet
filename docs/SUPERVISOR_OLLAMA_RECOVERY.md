# Удалённое восстановление Ollama через Supervisor

Supervisor предоставляет только фиксированные команды из allowlist. Произвольный PowerShell, `cmd.exe`, конвейеры, перенаправления и пользовательские аргументы не разрешены.

## Назначение

Набор команд восстанавливает локальный AI vision после ошибок вида:

- `WinError 10061` для `127.0.0.1:11434`;
- `HTTP 404 model not found` при пустом `ollama list`;
- устаревшая модель `hf.co/...GGUF` в `AI_VISION_MODEL`;
- тяжёлая comparison-модель `qwen3-vl:8b`;
- отсутствие capability `vision` у выбранной Ollama-модели;
- потеря перенесённого хранилища после настройки `OLLAMA_MODELS` на диск `E:`.

Целевая конфигурация фиксирована:

```dotenv
AI_VISION_ENABLED=true
AI_VISION_PROVIDER=ollama
AI_VISION_BASE_URL=http://127.0.0.1:11434
AI_VISION_MODEL=qwen3-vl:4b
AI_VISION_COMPARE_MODEL=
AI_VISION_TIMEOUT_SECONDS=600
```

## Диагностика хранилища

Команда `Ollama: состояние vision` дополнительно показывает:

- `OLLAMA_MODELS` текущего процесса Supervisor;
- `OLLAMA_MODELS` из рабочего project `.env`;
- пользовательскую и системную переменные Windows;
- наличие каталогов `blobs` и `manifests` в двух разрешённых вариантах:
  - `E:\OllamaModels`;
  - `E:\OllamaModels\models`;
- количество blob-файлов и manifest-файлов;
- стандартный каталог `%USERPROFILE%\.ollama\models`;
- рекомендуемый корректный каталог на `E:`.

Никакие произвольные пути из Telegram не принимаются.

## Команды

В безопасной консоли Supervisor, категория `AI: Ollama`:

- `Ollama: список моделей` — выполняет фиксированный `ollama list`;
- `Ollama: состояние vision` — показывает разрешённые `AI_VISION_*`, диагностику хранилища, доступность API и имена установленных моделей;
- `Ollama: запустить локальный сервер` — запускает `ollama serve` отдельным локальным процессом и ждёт API;
- `Ollama: настроить vision qwen3-vl:4b` — атомарно изменяет только шесть разрешённых ключей в рабочем `.env`;
- `Ollama: скачать qwen3-vl:4b` — запускает сервер при необходимости и выполняет фиксированный `ollama pull`;
- `Ollama: проверить vision qwen3-vl:4b` — вызывает `/api/show` и требует capability `vision`;
- `Ollama: восстановить vision qwen3-vl:4b` — восстанавливает хранилище на `E:`, конфигурацию, сервер, модель и capability `vision`.

Команды `Ollama: состояние vision` и `Ollama: восстановить vision qwen3-vl:4b` отображаются как быстрые кнопки безопасной консоли.

## Как выбирается каталог на E

Восстановление проверяет только два фиксированных варианта:

1. `E:\OllamaModels`;
2. `E:\OllamaModels\models`.

Корректным считается каталог, в котором одновременно существуют папки `blobs` и `manifests`. Если корректны оба варианта, выбирается каталог с большим числом manifest-файлов, затем blob-файлов.

После выбора модуль:

1. атомарно записывает `OLLAMA_MODELS` в рабочий project `.env`;
2. записывает ту же переменную в User Environment Windows;
3. обновляет окружение текущей recovery-команды;
4. останавливает только `ollama.exe` фиксированным `taskkill.exe` без shell;
5. запускает `ollama serve` с выбранным каталогом;
6. проверяет список моделей после переключения;
7. продолжает установку `qwen3-vl:4b`.

Если на `E:` существуют похожие каталоги, но ни один не содержит одновременно `blobs` и `manifests`, восстановление завершается ошибкой до скачивания новой модели. Это не позволяет молча создать второй набор моделей в неправильном месте.

Если оба разрешённых каталога на `E:` полностью отсутствуют, существующая конфигурация хранилища не изменяется.

## Удалённая последовательность

1. Выполнить `Обновить + рестарт`, чтобы Supervisor загрузил актуальный `main`.
2. Открыть `Безопасная консоль`.
3. Выполнить быструю команду `Ollama: состояние vision`.
4. Выполнить `Ollama: восстановить vision qwen3-vl:4b` и подтвердить точную команду.
5. После успешной проверки выполнить `Рестарт Supervisor`, а не только дочерний Velvet Bot.
6. Повторно проверить `Ollama: состояние vision`.
7. В панели Qwen убедиться, что активная модель отображается как `ollama:qwen3-vl:4b`.

## Повтор после таймаута

Supervisor ограничивает длительность команд значением `SUPERVISOR_COMMAND_TIMEOUT_SECONDS`. Если загрузка модели не успела завершиться, команду `Ollama: скачать qwen3-vl:4b` можно выполнить повторно: Ollama продолжит загрузку доступных слоёв.

## Файлы и логи

- рабочая конфигурация: `<SUPERVISOR_PROJECT_DIR>/.env`;
- лог отдельного сервера Ollama: `<SUPERVISOR_PROJECT_DIR>/logs/ollama-supervisor.log`;
- модуль восстановления: `velvet_supervisor/ollama_recovery.py`;
- реестр команд: `velvet_supervisor/remote_console.py`;
- быстрые кнопки: `velvet_bot/presentation/telegram/supervisor/remote_views.py`.

## Граница безопасности

Модуль сохраняет неизвестные и секретные строки `.env`. Он изменяет только фиксированные `AI_VISION_*` и `OLLAMA_MODELS`. Из Telegram невозможно передать другой путь, модель, команду оболочки или дополнительные аргументы. Выбор хранилища ограничен двумя заранее заданными каталогами на диске `E:`.
