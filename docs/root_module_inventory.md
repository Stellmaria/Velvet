# Инвентаризация корневых модулей Velvet

Этот документ фиксирует архитектурный контракт для файлов `velvet_bot/*.py` в рамках issue #418. Машинным источником истины является `scripts/inventory_root_modules.py`.

- неклассифицированных модулей: **0**.

Распределение по обязательным категориям:

- `worker`: **6**;
- `public facade`: **3**.

## Что хранит inventory

Для каждого корневого Python-модуля формируются:

- одна из шести разрешённых архитектурных категорий;
- правило, по которому категория назначена;
- список файлов-потребителей внутри репозитория;
- обнаруженные import-time вызовы, присваивания и управляющие конструкции;
- явный публичный контракт для модулей, оставленных как `public facade`.

## Публичные facade-контракты

На текущем baseline публичными facade могут оставаться только:

- `velvet_bot/access.py` как стабильная граница импорта access policy;
- `velvet_bot/config.py` как стабильная граница настроек;
- `velvet_bot/version.py` как стабильная граница версии приложения.

Любой новый facade обязан получить отдельное описание в реестре. Само по себе историческое расположение файла в корне не считается архитектурным аргументом, каким бы древним и почтенным ни был этот цифровой осадок.

## Защита от нового долга

Проверка падает, если:

- изменился состав или количество root modules без обновления baseline;
- появился модуль без утверждённой категории;
- используется категория вне разрешённого набора;
- facade не имеет явного публичного контракта.

Команда проверки:

```bash
python scripts/inventory_root_modules.py --check
```

Полный JSON с consumers и side effects:

```bash
python scripts/inventory_root_modules.py --json
```

## Runtime compatibility

Решения по восьми активным runtime compatibility-компонентам хранятся в `velvet_bot/presentation/telegram/runtime_contracts.py` и `docs/runtime_compatibility_inventory.md`. Для каждого уже выбран путь `remove-after-consumer-migration`; выполнение самих behavioral migrations остаётся отдельными небольшими PR и не изменяет факт завершения классификационного среза #418.
