# Velvet Brain Vault

Откройте корень репозитория `Velvet` как Vault в Obsidian и начните с
[[brain-vault/Home|Home]]. Все ссылки и файлы остаются обычным Markdown/JSON и
проверяются в CI.

Это долговременная база знаний и источник runtime-контекста. Она не является:

- очередью задач;
- хранилищем диалогов или необработанных логов;
- базой персональных данных;
- местом для токенов, `.env` и других секретов;
- заменой GitHub, PostgreSQL или orchestration ledger.

Runtime получает не весь Vault, а детерминированный context pack своей
сущности, указанный в `manifest.json`. Поэтому Velvet Coder не видит контекст
Max, Librarian не получает инструменты, а Каэль получает только управляющие
контракты и краткие memory seeds.
